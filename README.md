# یدکی (Yadaki) — فروشگاه اینترنتی لوازم یدکی خودرو

پلتفرم فروشگاهی لوازم یدکی خودرو با Next.js 15، PostgreSQL و پشتیبانی B2B (قیمت همکار/تعمیرگاه).

## راه‌اندازی سریع (لوکال)

```bash
# ۱) وابستگی‌ها
npm install

# ۲) دیتابیس
#    گزینه الف (پیش‌فرض): Postgres محلی روی 127.0.0.1:5432 با pg_hba trust
node scripts/setup-db.mjs
#    گزینه ب: داکر
docker compose up -d
#    و سپس DATABASE_URL را در .env به localhost:5433 تغییر دهید

# ۳) مایگریشن و دیتای اولیه
npx prisma migrate dev
npm run db:seed

# ۴) اجرا
npm run dev      # توسعه
npm run build && npm run start   # تولید
```

## ورود ادمین

- شماره: `09120000000` → کد OTP در کنسول سرور چاپ می‌شود (`SMS_PROVIDER=console`).
- کاربران نمونه: تعمیرگاه `09121111111` (MECHANIC)، مشتری `09122222222`.
- کوپن نمونه: `WELCOME10` (۱۰٪ تا سقف ۱۰۰ هزار تومان) و `FIRSTBUY` (۳۰۰٬۰۰۰ تومان).

## متغیرهای محیطی (`.env`)

| کلید | توضیح |
|---|---|
| `DATABASE_URL` | اتصال PostgreSQL |
| `AUTH_SECRET` | کلید امضای JWT (حداقل ۳۲ کاراکتر) |
| `NEXT_PUBLIC_SITE_URL` | آدرس پایه سایت (برای sitemap و کال‌بک پرداخت) |
| `PAYMENT_GATEWAY` | `sandbox` (پیش‌فرض) یا `zarinpal` |
| `ZARINPAL_MERCHANT_ID` | مرچنت آیدی زرین‌پال برای پرداخت واقعی |
| `SMS_PROVIDER` | `console` یا `kavenegar` یا `melipayamak` |

## قابلیت‌های پیاده‌سازی‌شده (فاز ۰–۱)

- انتخاب خودرو (برند ← مدل ← تیپ) و فیلتر سازگاری در همه لیست‌ها + هشدار ناسازگاری در صفحه محصول
- جستجو بر اساس نام، کد فنی، شماره قطعه، OEM و کدهای جایگزین + نرمال‌سازی «ي/ی» و «ك/ک» و اعداد فارسی
- صفحه محصول کامل: گالری، کدها، جدول سازگاری، مشخصات، نظرات و پرسش‌وپاسخ
- سبد خرید مهمان/کاربر (ادغام هنگام ورود)، کوپن، تسویه، پرداخت (لایه چنددرگاهی + زرین‌پال آماده)
- حساب کاربری: پروفایل، سفارش‌ها، آدرس‌ها، گاراژ خودروها
- پنل ادمین: داشبورد، محصولات (فعال/غیرفعال + اصلاح موجودی)، سفارش‌ها (تغییر وضعیت قانون‌مند + بازگشت موجودی)
- استعلام قیمت (`/quote`) و درخواست همکاری عمده (`/wholesale`)
- سئو: متادیتا، JSON-LD (Product/Breadcrumb)، sitemap، robots، PWA، 404 فارسی

## مستندات

- `docs/ARCHITECTURE.md` — معماری، استک، مدل داده، امنیت
- `docs/ROADMAP.md` — فازبندی، ریسک‌ها
- `docs/PAGES.md` — نقشه صفحات و جریان‌ها

## پرداخت واقعی (زرین‌پال)

1. `PAYMENT_GATEWAY=zarinpal` و `ZARINPAL_MERCHANT_ID` را در `.env` تنظیم کنید.
2. کال‌بک: `POST/GET /api/payment/callback?order=CODE` (زرین‌پال `Authority` و `Status` اضافه می‌کند) — تأیید سمت سرور انجام می‌شود.
